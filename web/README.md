# WwTool Web 端

> [!NOTE]
> Web 端还在开发中（分支 `dev-web`），目前没有公开部署。下面的说明面向想在本地运行或参与开发的人。

WwTool 的浏览器版本：界面、主题和动画与桌面端保持一致，后端复用桌面端的 `WwTool.Core`（抽卡解析与统计、账号资料映射、公告与挑战数据）。

- 前端：`web/`，Vue 3 + TypeScript + Vite，图表用 ECharts。
- 后端：`src/Web/`，ASP.NET Core 10 Minimal API，同源托管前端构建产物。

## 账号与安全

**游戏账号的密码和凭据不会交给后端。**

| 数据 | 在哪里 |
| --- | --- |
| 游戏邮箱、密码 | 只在浏览器内直连库洛登录，用完立即清空，不保存、不上传 |
| OauthCode（用于刷新账号资料） | 只保存在当前浏览器，以不可导出的密钥加密存放在 IndexedDB；可在账号页随时删除 |
| 抽卡链接 | 后端用它拉取一次抽卡记录，链接本身不保存 |
| 攻略站授权（Guide Token） | 只加密保存在当前浏览器；同步角色时随请求交给后端转发，后端不保存、不记录 |
| 抽卡记录（未登录） | 只保存在当前浏览器（IndexedDB）；统计时把记录发给后端计算，后端不保存 |
| 抽卡记录、账号资料（已登录） | 保存在后端，只对绑定了该 UID 的站点账号可见；账号资料由浏览器取得后把不含凭据的原始响应交给后端 |
| 站点密码 | 后端只保存 PBKDF2 哈希；忘记密码时用注册时给出的一次性恢复码重设 |

- **不登录也能用**：粘贴抽卡链接即可导入并查看统计，记录只在当前浏览器。登录后可以一键上传到云端（需要先绑定该 UID）。
- **站点账号**用用户名 + 密码登录，不收集邮箱，与游戏账号无关。连续输错 5 次锁定 15 分钟；修改或重设密码后，其他设备上的登录立即失效。
- **UID 绑定**有两种方式：提交该 UID 的有效抽卡链接（后端验证），或在浏览器里登录游戏账号（国际服），按浏览器上报的账号资料绑定其下全部 UID。两种方式都可以把已被别人绑定的 UID 转移到自己名下，原账号会收到提示。
- 账号页可以导出全部数据（JSON），也可以删除单个 UID 或整个站点账号。

## 功能

| 页面 | 内容 |
| --- | --- |
| 首页 | 账号卡与统计行、结晶波片 / 结晶单质 / 活跃度 / 先约电台 / 周本进度、便捷操作、游戏公告（国服 / 国际服启动器资讯与轮播图） |
| 活动 | 版本信息与剩余时间；时间线、版本日历、全部公告；国服前瞻兑换码；逆境深塔、冥歌海墟、终焉矩阵 |
| 抽卡统计 | 总览（统计卡、各卡池最近五星、未出金进度、近 30 天抽数、五星分布、不歪概率与四星比例）；单卡池的列表 / 精简 / 时间线视图；时间范围与五星类型筛选；详细图表。未登录时显示本地导入的记录 |
| 角色 | 已有角色 / 已装备武器，按星级分组，可按星级、名称、获取时间排序；点角色打开角色详情（概览、技能、共鸣链、我的养成、故事与语音），抽卡时间线上点角色头像也能打开 |
| 探索、摩托 | 与桌面端相同的数据 |
| 账号 | 登录 / 注册、修改密码与恢复码、绑定 UID（抽卡链接或游戏账号）、本地记录上传、导出与删除 |
| 设置 | 主题与强调色、窗口背景（启动器背景或自选图片）、动态背景、空白处查看背景、语言（简体中文 / English / 日本語）、减少动画；游戏资料条目数；关于 |

第一次进入网站时会弹出使用说明（每个浏览器一次，页脚「使用说明」可再次打开）。界面与桌面端一致：窗口背景取游戏启动器背景图与标语，右下角悬浮按钮放各页面的操作（如抽卡统计的「获取记录」），鼠标停在空白处会淡出界面以查看背景。自选背景图只保存在当前浏览器。

与桌面端的差别：

- **角色数据经服务器转发**：角色、武器数据来自官方攻略站，它只允许自己的域名跨域访问，浏览器无法直连。游戏登录时浏览器把 access_token 交给后端换一次 Guide Token（后端不保存、不记录），令牌加密保存在浏览器；之后每次同步时随请求带给后端转发，只有角色快照落库。
- 角色详情的资料来自 encore.moe，由后端缓存后转发（只接受游戏资料里的角色 ID）。
- 抽卡链接需要手动粘贴。账号页提供一行 PowerShell 命令，可从本机游戏日志中取出最新链接并复制到剪贴板（只读、不联网）。
- 启动游戏、打开目录、程序更新等桌面专属功能已移除，首页的便捷操作换成站内跳转；暂不支持手机等窄屏布局。

## 本地运行

需要 [.NET 10 SDK](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0) 与 Node.js 20.19 以上（Vite 7 的要求）。

```powershell
# 1. 构建前端，产物输出到 src/Web/wwwroot
cd web
npm install
npm run build

# 2. 启动后端，打开 http://localhost:5180
cd ..
dotnet run --project src/Web
```

开发前端时可以用热更新：先启动后端，再在 `web/` 下运行 `npm run dev`，打开 `http://localhost:5173`（`/api` 会代理到 5180）。

- 请用 `npm run dev` / `npm run build` 启动 Vite，不要直接运行 `npx vite`：仓库路径含 `#`（如 `C#`）时 Vite 无法解析模块，`scripts/vite.mjs` 会在临时目录建一个目录联接再启动。
- `npm run gen`（dev / build 时自动执行）从桌面端的主题、动效、语言文件和图标生成 `src/generated` 与 `public/` 下的资源，两者都不提交。
- 后端启动时 `wwwroot` 不存在就不会托管页面，第一次构建前端后需要重启后端。
- **开发预览**：Development 环境下（`appsettings.Development.json` 已打开 `WwTool:EnableDevTools`），本机可以不用密码登录一个开发账号并写入样例数据。在浏览器控制台执行：

  ```js
  const h = { 'X-WwTool': '1' };
  await fetch('/api/dev/session', { method: 'POST', headers: h });
  await fetch('/api/dev/seed', { method: 'POST', headers: h });
  ```

  正式环境不会注册这两个接口。

## 配置

`src/Web/appsettings.json` 中的 `WwTool` 节：

| 键 | 说明 |
| --- | --- |
| `DataRoot` | 数据目录（相对程序目录），存放站点库 `WebSite.db`、抽卡与资料库、登录 Cookie 的加密密钥 |
| `ContentSecurityPolicy` | 响应的 CSP 头；已放行游戏登录的安全验证与库洛接口、外部 https 图片（公告、encore.moe）、`blob:` 图片（自选背景）与同源视频（动态背景） |

所有非 GET 的 `/api` 请求都需要带 `X-WwTool: 1` 请求头；抽卡导入、资料上传、导出、访客统计和登录接口有频率限制。

## 目录

```
web/
├─ scripts/        gen-assets.mjs（从桌面端生成资源）、vite.mjs（Vite 启动包装）
├─ src/
│  ├─ shell/       页头悬浮岛、账号胶囊、窗口背景与空白处查看背景、悬浮按钮、使用说明
│  ├─ components/  通用组件（图表、弹窗、提示、公告正文等）
│  ├─ account/     站点会话
│  ├─ gacha/       本地抽卡记录（IndexedDB）、数据来源切换、上传
│  ├─ game/        浏览器内的游戏登录、OauthCode 加密存储、账号资料与角色同步、encore.moe 角色资料
│  └─ pages/       各页面
src/Web/
├─ Auth/           用户名密码登录、当前账号
├─ Uids/           UID 绑定、抽卡导入与查询、账号资料、访客统计
├─ Roles/          角色数据：攻略站无状态转发与角色快照
├─ Public/         公告、兑换码、挑战、启动器背景与资讯、角色详情等公开数据（后端共用缓存）
├─ Data/           站点数据库
├─ Platform/       Core 所需的平台实现（数据目录等）
└─ Dev/            开发预览接口
```

<a id="first-run"></a>
## 1. 初めて使うとき

### 1.1 アーカイブを選んで展開する

[Releases](https://github.com/conFess233/WwTool/releases) からアーカイブを 1 つ選びます。違いは [README · ダウンロード](README_ja.md#download) を参照してください。迷ったら `single-runtime` を選べば、展開してすぐ使えます。

1. アーカイブを書き込み権限のある場所（例：`D:\Tools`）に展開すると、`D:\Tools\WwTool` フォルダができます。`C:\Program Files` の下には置かず、`WwTool.exe` だけを取り出さないでください。
2. 一緒に展開される `portable` ファイルは残してください。このファイルがあると、設定とデータはこのフォルダに保存されます。削除すると `%LocalAppData%\WwTool` を使うようになり、それまでのデータが「見えなく」なります。
3. `WwTool.exe` を実行します。.NET が見つからないと表示された場合は、[.NET Desktop Runtime 10（x64）](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールするか、名前に `runtime` が付いたアーカイブに切り替えてください。

### 1.2 ゲームのインストールディレクトリを設定する

集音リンクの自動読み取り、**ゲームを起動**、スクリーンショット / ゲームフォルダ / ログフォルダのクイック操作は、ゲームディレクトリが必要です。

1. 上部ナビゲーション右端の歯車をクリックして **設定** を開きます。
2. **一般ゲーム設定 → ゲームインストールディレクトリ** で **パスを選択** をクリックします。
3. ランチャーのフォルダ（例：`D:\Wuthering Waves`）か、その中のゲームフォルダ（`D:\Wuthering Waves\Wuthering Waves Game`）を選びます。どちらでも構いません。

設定は変更から約 1 秒後に自動保存されます。右下の **設定を保存** ですぐに保存することもできます。

### 1.3 言語・テーマ・背景

すべて **設定 → UI設定** にあります。

- **ソフトウェア言語**：簡体字中国語・英語・日本語。切り替えるとすぐ反映されます。
- **テーマ / アクセントカラー**：明るいテーマや暗いテーマ、アクセントカラーを選べます。
- **ウィンドウ背景**：既定ではゲームランチャーの背景画像を使います（取得できない場合は模様を表示）。自分の画像に変えることもできます。
- **動く背景**：既定の背景を使っているとき、ランチャーの背景動画を再生します。ウィンドウが最小化されたりフォーカスを失ったりすると一時停止します。再生中は約 150～200 MB のメモリを追加で使用し、既定ではオフです。
- **余白で背景を見る**：マウスを余白（ウィンドウ周囲の余白やカードの間のすき間）にしばらく置くと、背景以外の表示が徐々に透明になり、背景を確認できます。いずれかの要素に移るとすぐ元に戻ります。透明度は調整でき、既定は 80%、0% でオフです。
- **ウィンドウのすりガラス効果**：切り替えは再起動後に反映されます。オフにするとソフトウェア描画になり、メモリ使用量が減ります。

<a id="accounts"></a>
## 2. アカウント

> アカウント情報は現在**国際版**のみ対応しています。集音記録だけを見たい場合は、この節を飛ばして [集音記録](#pulls) へ進んでください。

### 2.1 アカウントを追加する

1. ホームで **ゲームアカウントを追加** をクリックします。すでにアカウントがある場合は、右下の **＋** ボタンから **アカウントを追加** を選びます。
2. ゲームアカウントの **メールアドレス** と **パスワード** を入力し、**ログイン** をクリックします。
3. 「リスク制御が作動しました。ブラウザで本人確認を行っています…」と表示されたら、開いた Web ページで認証を完了してください。完了すると自動でログインが続きます。
4. ログインすると、このアカウントの UID が一覧表示され、データが一度取得されます。

ログインで得た認証コードは Windows DPAPI で暗号化してローカルに保存します。WwTool はパスワードを保存しません。

### 2.2 アカウントの切り替えと管理

右上の **アカウントカプセル**（アイコンとニックネーム）をクリックすると **アカウントデータ** ページが開きます。

- ローカルに保存した UID ごとにカードがあり、**このアカウントに切替** で切り替えます。
- 右下の **＋ → データを更新** で、現在のアカウントのデータを再取得します。
- **アカウントを削除** すると、そのアカウントのローカルのスナップショット、集音記録、ログイン認証情報も削除されます。**元に戻せません。**

**設定 → デフォルトゲームアカウント (UID)** で、起動時に選択されるアカウントを指定できます。

### 2.3 ログインの有効期限切れ

認証の有効期限が切れると、「○○ のログインが無効になりました」と表示されます。

- **再ログイン** をクリックし、同じメールアドレスでログインすると、すぐにデータが更新されます。
- そのアカウントが不要なら **アカウントを削除** をクリックします。

<a id="home"></a>
## 3. ホーム

### 3.1 アカウント情報とリソース

- 上部にニックネーム、レベル、**UID** を表示します。UID の後ろの小さなボタンで UID 全体をコピーでき、コピーすると緑のチェックマークが少しの間表示されます。
- その下の行は、活動日数、作成日、SOL3 フェーズ、サーバー、所持キャラクター数です。
- 5 枚のリソースカード：**結晶波長板**（全回復までの時間付き）、**結晶溶媒**、**活躍度**、**先駆ラジオ**、**週ボス報酬**（月曜 04:00 リセット）。カウントダウンは毎秒更新されます。

この情報は前回同期したときのスナップショットです。更新するには、アカウントカード右上の更新ボタン（同期中はアイコンが回転します）か、ホーム右下の **＋ → データを更新** をクリックします（アカウントデータ・探索データ・バイクデータのページにも同じボタンがあります）。ホームの **＋** には **アカウントリストを更新** と **アカウントを追加** もあります。

### 3.2 クイック操作

| ボタン | 動作 |
| --- | --- |
| ゲームを起動 | 設定のゲームディレクトリからゲームを起動します |
| スクリーンショット / ゲームフォルダ / ログフォルダ | 該当フォルダをエクスプローラーで開きます |
| ガチャリンクをコピー | ゲームログから集音リンクを読み取り、クリップボードにコピーします |
| ゲーム資料を同期 | キャラクター・武器・バイク・音楽アルバムの資料の更新をすぐに確認します |
| データフォルダ | WwTool がデータを保存しているフォルダを開きます |
| 公式攻略サイト | 庫街区の攻略サイトをブラウザで開きます |

### 3.3 お知らせ

- 右側にゲームランチャーのイベント・お知らせ・ニュースを表示し、上部はカルーセルです。項目をクリックするとブラウザで本文を開きます。
- タイトル横の **中国版 / 国際版** スライダーで取得元を切り替えます。選択は記憶されます。未選択の間は、現在のアカウントのサーバーに合わせます。
- **すべて / イベント / お知らせ / ニュース** で絞り込みます。一番下の **公式サイトですべて見る** で、選択中のサーバーのニュースページを開きます。
- 前回のキャッシュを先に表示し、バックグラウンドで更新します。取得に失敗した場合は前の内容を残します。

<a id="data-pages"></a>
## 4. キャラクター・探索・バイクデータ

これらのページは **前回ローカルに同期した** データを表示します。更新するには、各ページ右下の **＋ → データを更新** をクリックします。

- **キャラクターデータ**：所持キャラクター（レアリティ、共鳴チェーン）と装備中の武器。並べ替えができます。カードをクリックすると横に詳細が開き、半身立ち絵と攻略サイトから取得した属性を表示します（立ち絵がない場合はアイコン）。もう一度クリックするか、空いている所をクリックすると閉じます。
- **探索データ**：宝箱と潮汐の遺産の種類別の開封数。API が返す数値で、ゲーム内の探索度とは一致しません。
- **バイクデータ**：バイクのレベルと経験値、現在の装備、スキン・ステッカー・ペンダント・フレーム・車載音楽アルバムの解放状況。

<a id="pulls"></a>
## 5. 集音記録

集音統計は中国版・国際版の両方に対応し、**アカウントへのログインは不要**です。

### 5.1 記録を取得する

1. ゲームを起動し、**集音** を開いて **履歴** をクリックし、少なくとも 1 ページ表示します。このときゲームが集音リンクをログに書き込みます。
2. WwTool に戻り、**集音統計** を開いて **記録を取得** をクリックします。
3. WwTool はまずゲームログからリンクを探します。
   - 見つかった場合：すべてのバナーの記録を取得します。
   - 見つからない場合：**ガチャ履歴 URL の取り込み** ウィンドウが開きます。次の節を参照してください。
4. 取得が終わると記録はローカルに保存され、リンクの UID に対応するアカウントが自動で選択されます。

次回以降は新しい記録だけを追加します。既存の記録を重複して数えることはありません。

### 5.2 集音リンクを取り込む

**ガチャ履歴 URL の取り込み** ウィンドウ（右下の **＋ → URL を取り込む** からも開けます）で：

- **ゲームログから読み取る** をクリックしてもう一度自動で探すか、
- 入力欄にリンクを**貼り付け**ます。ログの行をまるごと貼り付けても、WwTool がリンクを抜き出します。
- **サーバー**（中国版 / 国際版）は通常リンクから自動判別されます。判別できない場合は手動で選んでください。

集音リンクや `Client.log` ファイルを集音統計ページに**ドラッグ＆ドロップ**することもできます。ドロップすると取り込みと記録の取得を自動で行います。

手動でリンクを探す場合：ゲームフォルダの `Client\Saved\Logs\Client.log` をテキストエディタで開き、`gacha/record/query` を検索して、それを含む URL 全体をコピーします。

> [!WARNING]
> 集音リンクにはアカウントの認証情報が含まれます。他人に送ったり、公開の場に貼ったりしないでください。

### 5.3 統計を見る

ページ上部のタブで **概要**、各バナー、**その他** を切り替えます。

- **概要**：全バナーの回数、★5 獲得数、平均星5排出回数、すり抜けなし率、星声消費と、各バナーの直近の ★5 と現在の天井カウント。すり抜けなし率はキャラクターイベントバナーだけを集計します。
- **個別のバナー**：そのバナーの全記録、現在の天井カウント、80 回の天井まであと何回か。
- **絞り込みと表示**：期間での絞り込み、★5 だけの表示、**リスト / コンパクト** の切り替え。コンパクト表示では ★5 をアイコンのタイルで表示します。
- **★5 の記録を右クリック**：この記録をコピー、キャラ詳細を見る、詳細グラフで表示、共有画像として書き出す。
- **詳細グラフ**：★5 排出回数の分布、バナー別の回数比率、★5 ごとの消費回数、レアリティ構成とすり抜けなし率、日別のガチャヒートマップ。

### 5.4 ローカルデータだけを使う

- オフラインでも保存済みの記録を見られます：右下の **＋ → ローカルデータを読み込む**。
- **設定 → ローカルデータを自動読み込み** をオンにすると、初めて集音統計を開いたときにローカルの記録を自動で読み込みます。

### 5.5 集音記録を消去する

**設定** ページ下部の **長押しでガチャ記録を消去**：完了するまでボタンを押し続けると、**現在のアカウント**の集音記録をすべて削除します。他のアカウントには影響しません。元に戻せず、6 か月より前の記録は公式から再取得できません。

## 6. 設定項目一覧

| グループ | 項目 | 内容 |
| --- | --- | --- |
| 一般ゲーム設定 | ゲームインストールディレクトリ | 集音リンクの読み取り、ゲームの起動、ゲーム関連フォルダを開く |
| | デフォルトゲームアカウント (UID) | 起動時に選択されるアカウント |
| | ローカルデータを自動読み込み | 初めて集音統計を開いたときにローカルの記録を読み込む |
| UI設定 | テーマ / アクセントカラー | 配色 |
| | ウィンドウ背景 | 既定のランチャー背景かカスタム画像 |
| | 動く背景 | ランチャーの背景動画を再生（既定の背景のときのみ） |
| | 余白で背景を見る | マウスを余白に置いたときに表示が透明になる度合い。既定 80%、0% でオフ |
| | ウィンドウのすりガラス効果 / 背景の不透明度 | 半透明のぼかし背景。切り替え後は再起動が必要 |
| | ソフトウェア言語 | 簡体字中国語 / 英語 / 日本語 |
| | 通知レベル | 重要でない通知の表示頻度。バックグラウンドの自動更新は常に通知なし |
| | モーションを減らす | 移動や拡大縮小をなくし、短いフェードだけを残す |
| ゲーム資料と画像キャッシュ | ゲーム資料を同期 / 画像キャッシュを削除 | 資料の更新をすぐ確認する。ダウンロード済みの画像を削除し、必要になったら再ダウンロードする |
| 実行ログ | ファイルログ出力を有効にする / 最小ログ記録レベル | 実行情報を `Local/Logs` に書き出す。トラブル調査用 |
| ネットワークと認証 | ログAPIマッチングキーワード | `Client.log` から集音リンクを探すキーワード。通常は変更不要 |
| | Geetest認証サービスポート | ログイン時の本人確認に使うローカルポート（既定 5000、使用中なら次の空きポート） |
| | リトライ回数 / 間隔 | 失敗したリクエストを自動で再試行する |

<a id="data"></a>
## 7. データ・バックアップ・アップデート

### 7.1 データの場所

`portable` ファイルがある場合、すべてのデータはプログラムフォルダにあります（ホームの **データフォルダ** ボタンで開けます）。

| 場所 | 内容 | 削除してよいか |
| --- | --- | --- |
| `Config\` | 設定 | 削除すると既定の設定に戻ります |
| `Local\Data\LocalData.db` | アカウントのスナップショット、集音記録、暗号化されたログイン認証情報 | **削除しないでください**。これがあなたのデータです |
| `Local\Data\*.json`、`Local\Language\`、`Local\Icons\` | 同梱のゲーム資料、言語、アイコン | アップデート時に上書きされます |
| `Local\Cache\` | 画像、ランチャー背景、お知らせのキャッシュ | いつでも削除できます |
| `Local\Logs\` | ログ | 削除できます |
| `Local\Backups\` | データベース更新前の自動バックアップ | 問題がなければ削除できます |

### 7.2 バックアップ

WwTool を終了し、`Config` と `Local\Data\LocalData.db` をコピーします。

### 7.3 新しいバージョンへのアップデート

1. WwTool を終了します。
2. 新しいアーカイブを既存の `WwTool` フォルダがある場所に展開し（`D:\Tools\WwTool` なら `D:\Tools` に展開）、同じ名前のファイルを上書きします。リリースアーカイブにはデータベースも設定も含まれないため、データはそのまま残ります。既存のフォルダ名が `WwTool` でない場合（1.x のフォルダなど）は、新しい `WwTool` フォルダの中身をすべて既存のフォルダにコピーして上書きしてください。
3. 新しい `WwTool.exe` を実行します。

1.x からのアップデートも同じ手順です。2.0 は 1.2.1 のデータベースとログイン認証情報をそのまま読み込めます。

### 7.4 別の PC や Windows ユーザーに移る

プログラムフォルダごとコピーします。ログイン認証情報は元の Windows ユーザーでしか復号できないため、移行後は各アカウントで **再ログイン** が必要です。集音記録などのデータには影響しません。

<a id="faq"></a>
## 8. よくある質問

**「記録を取得」を押すと毎回取り込みウィンドウが開き、リンクが見つからない**

- 設定のゲームインストールディレクトリが正しいか確認してください。
- ゲーム内で **集音 → 履歴** を開き、1 ページ表示したか確認してください。ゲームを再起動した後は、もう一度開く必要があります。
- それでも駄目な場合は、[5.2](#pulls) の手順で `Client.log` からリンクを手動でコピーしてください。

**記録の取得に失敗する**

- 集音リンクには有効期限があります。ゲーム内で **集音 → 履歴** をもう一度開いてから、**記録を取得** をクリックしてください。
- 「集音履歴のリンクはアカウント A のもので、選択中のアカウント B と一致しません」と表示された場合：リンクのアカウントに切り替えるか、現在のアカウントでゲーム内の履歴を開き直してください。

**ログイン時の本人確認ページが開かない**

ファイアウォールやセキュリティソフトがローカルポートをブロックしていないか確認し、**設定 → ネットワークと認証** で **Geetest認証サービスポート** を別の番号に変えて再試行してください。

**アイコンが既定の画像になる（Lite 版や新キャラクター）**

アイコンは初めて表示するときに GitHub からダウンロードします。オフラインの間は既定の画像を表示し、接続されると自動で補われます。設定の **ゲーム資料を同期** をクリックしても構いません。

**背景やお知らせが更新されない**

前回のキャッシュを先に表示しており、更新には少し時間がかかります。オフラインの間はキャッシュのままです。

**動く背景が動かない**

ウィンドウが最小化されているかフォーカスがない間は一時停止します。ウィンドウをクリックしてください。既定の背景のときだけ使え、再生に失敗した場合は静止画に戻ります。

**すりガラス効果を切り替えても変わらない**

この設定は WwTool の再起動後に反映されます。

**問題の報告**

<a id="first-run"></a>
## 1. 第一次使用

### 1.1 选择压缩包并解压

在 [Releases](https://github.com/conFess233/WwTool/releases) 选一个压缩包。各个包的区别见 [README · 下载](../../README.md#download)。不确定就选 `single-runtime`，解压就能用。

1. 把压缩包**完整解压**到一个你有写入权限的目录，例如 `D:\Tools\WwTool`。不要放在 `C:\Program Files` 下，也不要只拿出 `WwTool.exe`。
2. 保留解压出来的 `portable` 文件。有它，设置和数据都保存在这个目录里；删掉它，程序会改用 `%LocalAppData%\WwTool`，之前的数据就「看不见」了。
3. 运行 `WwTool.exe`。如果提示缺少 .NET，要么安装 [.NET Desktop Runtime 10（x64）](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)，要么换带 `runtime` 的包。

### 1.2 设置游戏安装目录

自动读取抽卡链接、「启动游戏」以及截图、游戏、日志目录这几个便捷操作都依赖游戏目录。

1. 点顶部导航最右侧的齿轮，进入 **设置**。
2. 在 **常规游戏设置 → 游戏安装目录** 点 **选择路径**。
3. 选择启动器所在目录（例如 `D:\Wuthering Waves`）或里面的游戏目录（`D:\Wuthering Waves\Wuthering Waves Game`），两种都可以。

设置改动后约 1 秒自动保存；右下角的 **保存设置** 可以立即保存。

### 1.3 语言、主题与背景

都在 **设置 → 界面设置** 里：

- **软件语言**：简体中文、English、日本語，切换后立即生效。
- **主题 / 强调色**：浅色、深色等主题，以及强调色。
- **窗口背景**：默认使用游戏启动器的背景图（拿不到时显示底纹），也可以换成自己的图片。
- **动态背景**：使用默认背景时，可以播放启动器的背景视频。窗口最小化或失去焦点时自动暂停，播放时大约多占 150～200 MB 内存，默认关闭。
- **窗口毛玻璃效果**：开关需要重启程序才生效；关闭后改用软件渲染，内存占用更低。

<a id="accounts"></a>
## 2. 账号

> 账号资料目前只支持**国际服**。只想看抽卡记录的话，可以跳过这一节，直接看 [抽卡记录](#pulls)。

### 2.1 添加账号

1. 在首页点 **添加游戏账号**；已经有账号时，点右下角的 **＋** 按钮，再选 **添加账号**。
2. 输入游戏账号的 **邮箱** 和 **密码**，点 **登录**。
3. 如果出现「触发风控，正在唤起网页进行安全验证」，在打开的网页里完成验证，完成后会自动继续登录。
4. 登录成功后，程序会列出这个账号下的角色（UID），并获取一次资料。

登录得到的授权码用 Windows DPAPI 加密后保存在本地，WwTool 不保存你的密码。

### 2.2 切换与管理账号

点右上角的 **账号胶囊**（头像和昵称），进入 **账号数据** 页：

- 每个本地保存的 UID 一张卡片，点 **切换到此账号** 切换；
- 右下角 **＋ → 刷新数据** 重新获取当前账号的资料；
- **删除账号** 会同时删除这个账号的本地快照、抽卡记录和登录凭据，**无法恢复**。

在 **设置 → 默认游戏账号 (UID)** 里可以指定每次启动默认选中的账号。

### 2.3 登录失效

授权过期后，页面会提示「××的登录已失效」：

- 点 **重新登录**，用同一个邮箱登录后会立刻刷新数据；
- 不再需要这个账号时，点 **移除账号**。

<a id="home"></a>
## 3. 首页

### 3.1 账号信息与资源

- 顶部是昵称、等级和 **UID**。UID 后面的小按钮可以一键复制完整 UID，复制成功后短暂显示绿色对勾。
- 下面一行是活跃天数、创建日期、索拉等级、服务器和拥有角色数。
- 五张资源卡：**结晶波片**（含回满时间）、**结晶单质**、**活跃度**、**先约电台**、**周本奖励**（周一 04:00 重置）。倒计时每秒更新。

资料是上次同步时的快照。要更新，进入 **账号数据**、**探索数据** 或 **摩托数据** 页，点右下角 **＋ → 刷新数据**。首页右下角的 **＋** 里是 **刷新账号列表** 和 **添加账号**。

### 3.2 便捷操作

| 按钮 | 作用 |
| --- | --- |
| 启动游戏 | 用设置里的游戏目录启动游戏 |
| 截图目录 / 游戏目录 / 日志目录 | 在资源管理器里打开对应目录 |
| 复制抽卡链接 | 从游戏日志里读取抽卡链接并复制到剪贴板 |
| 同步游戏资料 | 立即检查角色、武器、摩托与音乐专辑资料的更新 |
| 数据目录 | 打开 WwTool 保存数据的目录 |
| 官方攻略站 | 用浏览器打开库街区攻略站 |

### 3.3 游戏公告

- 右侧显示游戏启动器里的活动、公告与新闻，顶部是轮播图。点任意一条会在浏览器打开原文。
- 标题旁的 **国服 / 国际服** 滑块切换公告来源，选择会被记住。没选过时跟随当前账号的区服。
- **全部 / 活动 / 公告 / 新闻** 用来筛选。最下方 **前往官网查看全部公告** 打开对应区服的新闻页。
- 公告先显示上次的缓存，再在后台刷新；获取失败时保留旧内容。

<a id="data-pages"></a>
## 4. 角色、探索与摩托

这三页都显示**上次同步到本地**的数据。要更新，在对应页面点右下角 **＋ → 刷新数据**。

- **角色数据**：已拥有的角色（星级、共鸣链）和当前装备的武器，可以排序。点击角色卡会在旁边打开详情，显示半身立绘和攻略站返回的属性（没有立绘时显示头像）；再点一次或点空白处关闭。
- **探索数据**：各类奇藏箱与潮汐之遗的已开启数量。这是接口返回的计数，不等于游戏里的地图探索度。
- **摩托数据**：载具等级与经验，当前装备，皮肤、贴纸、挂饰、车架和车载音乐专辑的解锁情况。

<a id="pulls"></a>
## 5. 抽卡记录

抽卡统计国服、国际服都支持，**不需要登录账号**。

### 5.1 获取记录

1. 打开游戏，进入 **唤取**，点 **历史记录**，至少翻看一页。游戏这时会把抽卡链接写进日志。
2. 回到 WwTool，进入 **抽卡统计**，点 **获取记录**。
3. 程序先自动从游戏日志里找链接：
   - 找到了：直接获取所有卡池的记录；
   - 没找到：弹出 **导入抽卡链接** 窗口，见下一节。
4. 获取完成后，记录保存在本地，并按链接里的 UID 自动选中账号。

以后再获取时，只会补上新增的记录，已有的记录不会重复计数。

### 5.2 导入抽卡链接

在 **导入抽卡链接** 窗口里（也可以从右下角 **＋ → 导入链接** 打开）：

- 点 **从游戏日志读取**，再试一次自动查找；
- 或者把链接**粘贴**进输入框。粘贴整行日志也可以，程序会自己提取链接；
- **服务器**（国服 / 国际服）通常按链接自动识别，识别不了时手动选择。

也可以直接把抽卡链接或 `Client.log` 文件**拖进**抽卡统计页，松手后自动导入并获取记录。

手动找链接：用文本编辑器打开游戏目录下的 `Client\Saved\Logs\Client.log`，搜索 `gacha/record/query`，复制包含它的那一整段网址。

> [!WARNING]
> 抽卡链接里含有你账号的认证信息，不要发给别人或贴到公开场合。

### 5.3 查看统计

页面顶部的标签切换 **总览**、各个卡池和 **其他卡池**。

- **总览**：全部卡池的抽数、五星数、平均每金、不歪率和星声花费，以及各卡池最近的五星和当前已垫抽数。不歪率只统计角色活动池。
- **单个卡池**：这个卡池的全部记录、当前已垫抽数和距离 80 抽保底还差多少。
- **筛选与视图**：按时间范围筛选、只看五星，或在 **列表 / 精简** 之间切换。精简视图用头像磁贴显示每次出金。
- **右键五星记录**：复制这条记录、查看角色详情、在详细图表中定位，或导出为分享图片。
- **详细图表**：五星出货抽数分布、各卡池抽数占比、每个五星花费的抽数、稀有度构成与不歪率，以及每日抽卡热力图。

### 5.4 只用本地数据

- 不联网也能看已经保存的记录：右下角 **＋ → 加载本地数据**。
- **设置 → 自动加载本地数据** 打开后，第一次进入抽卡统计时自动读取本地记录。

### 5.5 清空抽卡记录

**设置** 页底部的 **按住清空抽卡数据**：按住按钮直到完成，会删除**当前账号**的全部抽卡记录，其他账号不受影响。清空后无法恢复，超过 6 个月的记录也无法再从官方取回。

## 6. 设置项一览

| 分组 | 设置项 | 作用 |
| --- | --- | --- |
| 常规游戏设置 | 游戏安装目录 | 读取抽卡链接、启动游戏、打开游戏相关目录 |
| | 默认游戏账号 (UID) | 启动时默认选中的账号 |
| | 自动加载本地数据 | 第一次进入抽卡统计时读取本地记录 |
| 界面设置 | 主题 / 强调色 | 外观配色 |
| | 窗口背景 | 默认启动器背景或自定义图片 |
| | 动态背景 | 播放启动器背景视频（只在默认背景下可用） |
| | 窗口毛玻璃效果 / 背景不透明度 | 半透明模糊背景，开关后需重启 |
| | 软件语言 | 简体中文 / English / 日本語 |
| | 通知强度 | 非必要提示的显示频率；后台自动刷新始终静默 |
| | 减少动画 | 去掉位移和缩放，只保留简短的淡入淡出 |
| 游戏资料与图片缓存 | 同步游戏资料 / 清理图片缓存 | 手动检查资料更新；删除已下载的图片，用到时会重新下载 |
| 运行日志 | 启用文件日志 / 最低日志级别 | 把运行信息写入 `Local/Logs`，排查问题时使用 |
| 网络与验证 | 日志 API 匹配关键字 | 在 `Client.log` 中查找抽卡链接用的关键字，一般不要改 |
| | 极验验证服务端口 | 登录安全验证用的本地端口（默认 5000，被占用时自动顺延） |
| | 重试次数 / 延迟 | 请求失败时自动重试 |

<a id="data"></a>
## 7. 数据、备份与更新

### 7.1 数据在哪里

带 `portable` 文件时，所有数据都在程序目录里（首页 **数据目录** 按钮可以直接打开）：

| 位置 | 内容 | 能否删除 |
| --- | --- | --- |
| `Config\` | 设置 | 删除后恢复默认设置 |
| `Local\Data\LocalData.db` | 账号快照、抽卡记录、加密的登录凭据 | **不要删**，这是你的存档 |
| `Local\Data\*.json`、`Local\Language\`、`Local\Icons\` | 随包的游戏资料、语言和图标 | 更新时会被覆盖 |
| `Local\Cache\` | 图片、启动器背景、公告缓存 | 可以随时删除 |
| `Local\Logs\` | 运行日志 | 可以删除 |
| `Local\Backups\` | 数据库升级前的自动备份 | 确认正常后可以删除 |

### 7.2 备份

退出 WwTool，复制 `Config` 和 `Local\Data\LocalData.db` 即可。

### 7.3 更新到新版本

1. 退出 WwTool。
2. 把新压缩包解压到原目录，选择覆盖。发布包里不含数据库和设置，不会覆盖你的存档。
3. 运行新的 `WwTool.exe`。

从 1.x 更新的步骤也一样：2.0 能直接读取 1.2.1 的数据库和登录凭据。

### 7.4 换电脑或换 Windows 用户

把整个程序目录复制过去即可。登录凭据只能由原来的 Windows 用户解密，所以到新环境后需要对每个账号 **重新登录**；抽卡记录和其他数据不受影响。

<a id="faq"></a>
## 8. 常见问题

**点「获取记录」后一直弹出导入窗口，找不到链接**

- 确认设置里的游戏安装目录正确。
- 确认在游戏里打开过 **唤取 → 历史记录** 并翻过一页。重启游戏后需要重新打开一次。
- 仍然不行时，按 [5.2](#pulls) 手动从 `Client.log` 复制链接。

**获取记录失败**

- 抽卡链接有时效。在游戏里重新打开一次 **唤取 → 历史记录**，再点 **获取记录**。
- 提示「抽卡链接属于账号 A，与当前选中的账号 B 不一致」：切换到链接对应的账号，或在游戏里用当前账号重新打开一次历史记录。

**登录时安全验证的网页打不开**

检查是否有防火墙或安全软件拦截本地端口；在 **设置 → 网络与验证** 里换一个 **极验验证服务端口** 再试。

**图标显示成默认图（Lite 版或新角色）**

图标会在第一次显示时从 GitHub 下载。网络不通时显示默认图，联网后会自动补上。也可以在设置里点 **同步游戏资料**。

**背景或公告没有更新**

先显示的是上次的缓存，后台刷新需要一点时间；网络不通时会一直显示缓存。

**动态背景不动**

窗口最小化或失去焦点时会暂停，点回窗口即可。只在使用默认背景时可用。播放失败时会自动退回静态背景。

**毛玻璃开关没反应**

这个设置需要重启 WwTool 才生效。

**反馈问题**

到 [Issues](https://github.com/conFess233/WwTool/issues) 提交，附上问题描述和 `Local\Logs` 里的日志。提交前请检查并隐去邮箱、完整的抽卡链接、令牌等个人信息。

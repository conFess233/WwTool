WwTool は『鳴潮』のアカウント情報を確認し、集音履歴を整理する Windows デスクトップツールです。複数のアカウントと UID、ローカル保存、簡体字中国語・英語・日本語の表示に対応しています。

<a id="features"></a>
## 機能

| 機能 | 内容 |
| --- | --- |
| アカウント概要 | ニックネーム、UID、レベル、ソラランク、活動状況、週ボス報酬回数と先駆ラジオ情報 |
| 共鳴者情報 | 所持共鳴者、共鳴チェーンの解放状況と装備武器。詳細カードに立ち絵と攻略サイトから取得できた一部ステータスを表示 |
| 集音統計 | 履歴 URL の自動・手動取り込み、集音タイプ別の星5履歴、現在の累積回数、星5獲得までの平均回数と全体集計 |
| グラフ | 集音タイプ比較、レアリティ分布、時系列と活動ヒートマップ。絞り込みに対応 |
| 探索・バイク | API が返す収集数、宝箱・潮汐の遺産の記録、バイク・外観・車載音楽の解放状況 |
| ゲーム資料 | 共鳴者・武器・バイク・音楽アルバムの資料を本リポジトリから個別同期。画像は必要に応じてキャッシュ |
| 外観設定 | 複数のテーマ、アクセントカラー、すりガラス効果、透明度と動きを抑える設定 |

アカウント情報は現在グローバル版が対象で、メールアドレスとパスワードによるログインが必要です。集音履歴は中国版・グローバル版に対応し、単独でも利用できます。

<a id="quick-start"></a>
## 導入

1. Windows 10 以降の x64 環境で、[.NET Desktop Runtime 10（Windows x64）](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) をインストールします。ダウンロードページではデスクトップランタイムを選んでください。
2. [Releases](https://github.com/conFess233/WwTool/releases) から `WwTool.zip` をダウンロードし、書き込み可能なフォルダーにすべて展開します。
3. `WwTool.exe` を起動します。付属リソースとローカルデータのフォルダーも必要なため、EXE だけを移動しないでください。
4. 以下の手順でアカウントを追加するか、集音履歴を取り込みます。詳細は [使い方ガイド](Help_ja.md) を参照してください。

<details>
<summary>ソースからビルド</summary>

[.NET 10 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) をインストールし、Windows 上で実行します。

```powershell
git clone https://github.com/conFess233/WwTool.git
cd WwTool
dotnet build WwTool/WwTool.csproj -c Release
```

`WwTool/bin/Release/net10.0-windows/WwTool.exe` を実行します。.NET 10 に対応する開発環境で `WwTool.slnx` を開くこともできます。

</details>

<a id="usage"></a>
## 使い方

### アカウントと共鳴者を確認

1. ホームでアカウントを追加し、メールアドレスとパスワードを入力します。認証が必要な場合は、開いたブラウザーで完了してください。
2. 対象 UID を選んでクラウドデータを取得し、アカウント・共鳴者・探索・バイクのページを開きます。
3. 共鳴者のアイコンに **0.5 秒** カーソルを合わせると、カードがフェードインします。左側に半身の立ち絵とその下に名前、右側に取得できたステータスと装備武器、右下に判明している獲得日時を表示します。

キーボードでフォーカスした場合も表示でき、`Esc` で閉じられます。カードは最後に同期したローカルデータを使用し、ホバー時に共鳴者データを再取得しません。更新する場合はクラウドデータを再取得してください。

### 集音履歴を取り込む

1. 自動取り込みを使う場合は設定でゲームフォルダーを選び、ゲーム内で一度集音履歴を開きます。
2. 統計ページでログから URL を自動取得するか、手動で履歴 URL を貼り付けてサーバーを選択します。
3. 記録を取得して概要とグラフを確認します。以後は UID を選んで保存済みのローカル記録を読み込めます。

再取り込みで同じ記録が二重加算されることはありません。同時刻の10連は取得元の順序を維持し、実際に重複した結果は保持します。星5までの平均回数は直近の星5獲得までを対象とし、その後の累積回数は別に表示します。星5記録がない場合、平均は空欄になります。

<a id="settings"></a>
## 設定

| 項目 | 用途 |
| --- | --- |
| ゲームパス | 履歴 URL の自動取得。`Wuthering Waves Game` を含むランチャーフォルダー、またはゲームフォルダーを選択 |
| 言語・外観 | 言語、テーマ、アクセントカラー、すりガラス、透明度と動きの調整 |
| ゲーム資料同期 | 4分類のバージョン、件数、同期結果と最終成功日時を確認。手動同期・キャンセルに対応 |
| 画像キャッシュ | キャッシュを削除し、次回使用時に必要な画像を再ダウンロード |

起動後、各分類の最終同期成功から24時間が経過している場合に資料を確認します。本リポジトリのデフォルトブランチにある資料のみを使用し、失敗時は既存データを保持します。資料バージョン（例：`3.7.0`）とツールのバージョン（`1.2.1`）は別に管理します。

<a id="data"></a>
## データとプライバシー

- 設定、アカウントの保存データと集音記録はプログラムフォルダーに保存します。更新前に終了してバックアップし、展開時に保存データを上書きしないでください。
- 保存するログイン認証情報は Windows DPAPI により現在の Windows ユーザーに対して暗号化します。別の PC や Windows ユーザーへ移動すると再ログインが必要になる場合があります。データベース全体が暗号化されるわけではありません。
- ログインとクラウドデータ取得は対象のゲームサービス、資料同期と不足アイコンのダウンロードは GitHub にアクセスします。半身の立ち絵は攻略サイトの保存データに含まれる公式画像 URL から取得します。
- 履歴 URL には認証情報が含まれる場合があります。問い合わせ時はパスワード、トークン、完全な履歴 URL と個人のアカウント情報を伏せてください。
- 画像キャッシュは `Local/Cache/Images`、標準のログ保存先は `Local/Logs` です。画像キャッシュを削除しても集音記録は消えません。

<a id="limitations"></a>
## 制限事項

- **一部の情報のみ：** API が実際に返した値を表示します。完全な共鳴者ステータスや音骸のサブステータスは保証されず、不明な値をゼロとして扱いません。探索の件数もマップ全体の探索率ではありません。
- **不明な獲得日時：** 取り込み済みの集音記録から確定できる場合に表示します。記録がない場合や対象外の共鳴者は不明と表示します。
- **履歴の範囲：** サーバーが現在提供している記録のみを取り込めます。未取り込みで、すでに提供されなくなった記録はローカル保存から復元できません。
- **同期の失敗：** ネットワーク、ログイン状態や API の変更により取得に失敗する場合があります。資料・画像の更新失敗時は有効な旧データを保持するため、後で再試行してください。
- **画像・名前の欠落：** 既存キャッシュ、アイコンや既定画像に切り替えます。使用可能な名前がない未完成資料は元データに保持し、一時的に表示を省略します。

詳しい操作とトラブルシューティングは [使い方ガイド](Help_ja.md) を参照してください。
